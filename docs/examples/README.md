## Overview

Welcome to the Structurizr MCP Server examples and tutorials! This section provides hands-on guidance for creating C4 architecture diagrams using the MCP server with Claude.

Each example is designed to teach you specific concepts and techniques, from basic C4 modeling to complex real-world architectures.

---

## Getting Started Examples

### Basic C4 Model Tutorial

**[Basic C4 Model](basic-c4.md)** - Perfect for beginners

Learn the fundamentals of C4 modeling by creating a simple internet banking system with:
- System Context diagram (people and systems)
- Container diagram (applications and databases)
- Component diagram (internal structure)
- Relationships and auto-layout

**Time:** 15 minutes | **Difficulty:** Beginner

**You'll learn:**
- Creating workspaces and managing elements
- Building all four C4 abstraction levels
- Creating and styling views
- Exporting to DSL and other formats

## Real-World Examples

### E-Commerce Platform

**[E-Commerce System](ecommerce.md)** - Intermediate complexity

Build a complete e-commerce platform architecture featuring:
- Multiple software systems (web app, mobile app, admin portal)
- External integrations (payment, shipping, email)
- Container-level architecture with databases and services
- Dynamic views showing checkout flow

**Time:** 30 minutes | **Difficulty:** Intermediate

**You'll learn:**
- Modeling complex multi-system architectures
- Working with external dependencies
- Creating dynamic sequence diagrams
- Adding comprehensive documentation

### Microservices Architecture

**[Microservices Example](microservices.md)** - Advanced patterns

Design a distributed microservices architecture with:
- Service mesh and API gateway patterns
- Multiple microservices with specific responsibilities
- Message queues and event-driven communication
- Service discovery and monitoring

**Time:** 45 minutes | **Difficulty:** Advanced

**You'll learn:**
- Modeling distributed systems
- Representing service-to-service communication
- Documenting microservice boundaries
- Analyzing dependencies in complex systems

## Learning Path

We recommend following this learning path based on your experience:

### Absolute Beginners

1. Start with **[Quick Start](../getting-started/quick-start.md)** (5 minutes)
2. Complete **[Basic C4 Model](basic-c4.md)** (15 minutes)
3. Review **[The C4 Model](../architecture/c4-model.md)** concepts

### Intermediate Users

1. Build the **[E-Commerce Example](ecommerce.md)** (30 minutes)
2. Explore **[Tools Reference](../tools/overview.md)** for all capabilities
3. Try **[MCP Prompts](../prompts/overview.md)** for AI assistance

### Advanced Users

1. Implement **[Microservices Architecture](microservices.md)** (45 minutes)
2. Study **[Advanced Topics](../advanced/extending.md)**
3. Review **[Migration Guide](migration.md)** for team adoption
